# Intelligent Routing
**Technical level:** Medium 
<br>
**Industry:** Any 
<br>
**Use Cases:** Human Task Orchestration 

## Summary

This process blueprint exemplifies the use of AI to intelligently route customer inquiries to the appropriate department. It utilizes the OpenAI, Azure OpenAI or Huggingface connectors for processing signals within a business context, ensuring that each task is assigned based on the optimal path for efficiency and resolution.

---

## 🚀 Zero-config LLM on Camunda SaaS

**Running on Camunda SaaS?** Skip the hassle of setting up an external AI provider. This blueprint is pre-configured to use the **Camunda-provided LLM** — a fully managed model that works out of the box. The required secrets (`CAMUNDA_PROVIDED_LLM_API_ENDPOINT` and `CAMUNDA_PROVIDED_LLM_API_KEY`) are automatically available on Camunda SaaS — no external API keys, no third-party accounts, no configuration required.

👉 [Learn about the Camunda-provided LLM](https://docs.camunda.io/docs/components/agentic-orchestration/camunda-provided-llm/)

Just deploy your process to your SaaS cluster and start routing intelligently from day one.

## EU AI Act Transparency Tagging Guidance (Article 50(2))

Use a clear label for AI-assisted routing suggestions before final human decision.

- The form already shows this pattern in `WorkOnInquiry.form`.
- Keep the disclosure close to routing controls (before or after is fine if it stays visible).
- Keep human override options available (`resolved`, `feedback`, manual team routing).
- Example text: `AI-generated classification: This routing recommendation was generated by an AI system and should be reviewed by a human before final routing.`

Use the current form implementation as the recommended how-to example.
